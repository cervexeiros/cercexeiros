Entrar al área privada

Para editar el blog necesitas una llave de acceso de GitHub (un «token») de la cuenta de la asociación. Solo hay que crearla una vez.

¿Cómo consigo la llave?
  1. Entra en GitHub con la cuenta cervexeiros.
  2. Abre Crear token (fine-grained).
  3. Nombre: «Área privada web». Caducidad: la que prefiráis (por ejemplo, 1 año).
  4. En Repository access elige Only select repositories y marca cercexeiros.
  5. En Permissions → Repository permissions, pon Contents en Read and write.
  6. Pulsa Generate token, copia la llave y pégala aquí.

Guárdala en un sitio seguro: quien la tenga puede cambiar la web.

Probar en modo demostración (no guarda nada de verdad).
