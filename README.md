# Cervexeiros Caseiros Pontevedra

Web da Asociación de Cervexeiros Caseiros de Pontevedra (ACCP), publicada con GitHub Pages.

- `index.html`, `quen-somos.html`, `actividades.html`, `faite-socio.html`, `contacto.html`: páxinas principais.
- `novidades/`: entradas de actividades.
- `assets/css/estilo.css`: cores e tipografías da marca.
- `assets/img/`: logo, ilustracións e imaxes.
